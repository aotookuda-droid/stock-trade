# 予想手順 — 7ステップ・メソッド

> レースを予想する際の標準手順。上から順に実行する。
> （`betting_strategy.md` が「どう買うか」、本書が「どの馬を選ぶか」。2つで1セット）

## 流れの全体像
**馬場を決める → 展開を読む → 消去する → 危険な人気馬を外す → 印で絞る → 最後に世間の評価と照合**

加点ではなく**減点**で絞り、自分の結論を出してから世間（新聞・オッズ）と突き合わせて妙味を探す——
これは数値ツール `bet_optimizer.py` の「モデル確率 vs 市場オッズ」と、まったく同じ思想の“手作業版”。

---

## ① トラックバイアス（馬場の偏り）を最初に設定する
内と外どちらが伸びるか、前残りか差し届くかを**最初に決める**ことで、最後までブレずに選べる。
- チェック：コース替わりの有無 / 天候 / その競馬場の**直近レースの好走馬**（特に**6番人気以下**の好走パターン）
- 結論を1つの方針に：「**外枠の差し追込有利**」か「**内枠の先行有利**」か。

▶ ここを最初に固定するのが肝。後から馬に合わせて馬場解釈を変える＝典型的な負けパターンを防げる。

## ② 厩舎コメントの確認
- 差し追込馬の厩舎が「積極的に行かせる」、休み明け馬が「万全の仕上がり」等を残しているか。
- **脚質変更の示唆は特に重要**（展開予想に直結）。
- ※有料が多いので、確認できればでOK。

## ③ 絶対にこない馬を切る（減点方式）
**加点方式は競馬では絶対NG。減点方式で消す。**
- 例：近走の勝ち馬から**1.5秒以上**離されている / 距離・コースが極端に不適 / 年齢的にピーク過ぎ
- **絶対条件：少しでも迷ったら、その馬は「保留」**（無理に消さない）。

▶ 消去法は荒れるレースで強い。残った中に「見落とされた穴」が混じる。
▶ 逆に、消し切れず頭数が多く残るなら、それは「**軸1点でなく三連複/ワイドで網を張るレース**」というサイン。

## ④ 展開予想をする
- **「逃げ馬」ではなく「逃げ先行馬」の数**に注目（ペースは“前に行きたい馬の総数”で決まる）。
- それらの枠順 / 差し追込とのバランス / 前走の上がりタイムの分布。
- ①（馬場）と組み合わせて、「馬場＋展開」の具体的結論を出す。

▶ これはシミュレーションの“隊列前圧（逃げ1.0＋先行0.45）でペースを決める”ロジックそのもの。手と数字で同じことをやっている。

## ⑤ 危険な人気馬チェック
次に当てはまる**人気馬**は危険信号 → 評価を下げる/軸から外す：
- 前走で逃げて好走 / 半年以上の休み明け / 特殊条件（重・不良など）での勝ち
- 芝の外枠替わり / ダートの内枠替わり / 牝馬限定戦 → 牡馬混合戦への参戦

▶ 過剰人気の馬を外すこと＝EVの源泉。市場が高く買う馬を疑うのが妙味の入口。

## ⑥ 印を打つ（〜6頭に絞れれば理想）
| 印 | 意味 |
|---|---|
| 狙 | 馬券的に狙いたい馬 |
| 穴 | 3着以内に来そうな穴馬 |
| 大穴 | 穴より更に人気薄で3着内がありそう |
| 注 | 一変に注意したい馬 |
| ◎ | 勝つと思う馬 |
| ◯ | 馬券内は堅いと思う馬 |
| △ | 1着も想定する馬 |
| ▲ | 3着以内に来そうな馬 |
| 抑 | 来なければ嬉しいが消せない人気馬（例：宝塚のレガレイラ）or 気になる穴馬 |

- **6頭くらいに絞れれば理想**。絞れない＝自信がない → **見送りを検討**。

## ⑦ 競馬新聞の印を「最後に」見る
- 必ず最後。先に見ると予想が引っ張られる。
- **狙/穴の馬に新聞の印がなければ＝人気薄＝妙味あり → 勝負レース認定。**
- 印が集中していたら → 別の馬を軸にするか、見送りを検討。

▶ 現代では「netkeibaの予想オッズ・AI印・SNS」も同じ“世間の評価”として使える。役割は新聞と同じ。

---

## ⑧（追加提案）印 → 券種・配分へ橋渡しする
①〜⑦で「どの馬か」は出る。最後に「**どう買うか**」へ変換する：
- 着順イメージが明確で相手も絞れる → 三連単/馬連（`betting_strategy.md` 参照）
- 荒れる・穴が複数（府中牝馬Sタイプ）→ 三連複の軸流し or ワイドの人気×穴/穴×穴
- 確信が1頭に集中 → 単勝（4.0〜9.9倍ゾーン）
- 配分は均等NG。確信度を金額に反映 →`bet_optimizer.py` で回収率・2倍以上確率を検算。

## 次の実戦：府中牝馬S（6/21・東京芝1800m・G3ハンデ・牝馬限定）での当てはめ
- ① 馬場：当週の東京芝の内外バイアス・天候を確認（梅雨で渋れば波乱増）
- ③⑤ 消去：人気がアテにならないレース。危険人気馬を積極的に外す
- ④ 展開：中団より前＋上がり優秀が王道（逃げ切り・追込は割引）。枠は不問
- ⑥⑦ 穴に印 → 新聞ノーマークなら勝負、印集中なら再考
