## 出走馬データについて

**出走馬名・騎手名・斤量・脚質はすべて架空のサンプルです。**
出馬表を掲載しているサイト（netkeiba / 競馬ラボ / スポーツナビ / 東スポ競馬）への接続が
実行環境のネットワークポリシーで遮断されており、実データを取得できなかったためです。

ページ下部の「出走馬データを編集」に実際の出馬表を貼り付ければ、そのメンバーで走ります。
書式は1行1頭のカンマ区切りで、

```
馬番, 馬名, 騎手, 斤量, 脚質, 能力
3, ノースアクセル, 手稲, 57.5, 逃げ, 56
```

- 脚質は `逃げ` / `先行` / `差し` / `追込`
- 能力は40〜60程度の目安値（大きいほど強い）。人気や実績から見積もった値を入れてください

## シミュレーションの中身

0.05秒刻みで各馬の速度を計算します。主な要素は次のとおりです。

- **基準ペース** — 距離に応じた馬場全体の流れ。逃げ馬の頭数でハイ／スローに振れる
- **位置取り** — 脚質ごとの目標位置（先頭との差）に合わせて速度を調整する
- **追い出し** — 残り600m付近から位置取りを捨て、各馬の限界速度で走る
- **余力** — 有酸素で維持できる速度を超えた分だけ削れ、尽きると失速する
- **風圧** — 前を走る馬ほど余力の消耗が早い（逃げのコスト）
- **コース取り** — 4コーナーで後方にいた馬ほど外を回るロスを負う。前が壁になることもある
- **斤量・枠順・当日の出来** — 1kgあたり約0.25秒/2000mの補正ほか

### 検証

```
node race-sim/check_sim.js 400              # サンプル出走馬で400レース分の分布
node race-sim/check_sim.js 400 sweep neutral # 能力を揃えた中立フィールドで脚質バランスを確認
```

能力・斤量を揃えて脚質だけ4頭ずつにした中立フィールドでの勝率は
逃げ12%／先行38%／差し38%／追込12%程度で、実際のJRA芝中距離の傾向に近い分布になります。
サンプル出走馬での勝ち時計は1:59前後、上がり3Fは34秒台に収まります。
