# 重賞 馬券購入ルール（機械判断用）

的中率は度外視し、期待値と回収率だけを追う。定性判断（敗因精査・調教評価など）は分析者が行い、
その結果を `keiba/engine.py` に入力して、確率・期待値・買い目・金額は機械的に算出する。

## 0. 対象と予算

- 対象: JRA平地重賞のみ（障害重賞・地方交流重賞は対象外）
- 1レース上限 4,000円、土日合計上限 8,000円。100円単位
- 週末の重賞が3つ以上のときは2つだけ買う（選定は §1）
- 期待値のある馬券がなければ **見送り（0円）**。上限を使い切る必要はない

## 1. レース選定（重賞3つ以上の週）

枠順確定後（木・金曜）に予想オッズで決める。`select_races()` のスコアが高い順に2レース。

| 要素 | 加点 |
|---|---|
| 出走頭数 | 頭数 × 1 |
| ハンデ戦 | +3 |
| 1番人気の単勝オッズ | min(オッズ, 5) × 2（混戦ほど高い） |

## 2. タイムライン

| タイミング | 作業 |
|---|---|
| 前日（枠順確定後） | 近走の敗因精査・レースレベル判定、脚質構成とペース予想、調教・厩舎コメント評価、減点/加点要素の判定 |
| 発走1時間前 | 当日のトラックバイアス確定、馬体重チェック（±15kg）、最終オッズ取得 → `engine.py` で買い目算出 |

「販売1時間前」は **発走1時間前** と解釈する。この時点のオッズを最終とする。

## 3. トラックバイアス

当日・同じ馬場（芝/ダート）で行われた前のレースの3着以内馬から算出（`track_bias()`）。

- 内外: 馬番を頭数で 0（最内）〜1（大外）に正規化し、0.5 からのずれを平均 → 負なら内有利
- 前後: 4角通過順を頭数で正規化し、0.5 からのずれを平均 → 負なら前有利
- ±0.08 未満はフラット扱い。当日データが3レース未満なら前週の同コースで補う
- Aコース→B/Cコース替わり初週は内有利側に補正して判断してよい

## 4. 脚質構成とペース

過去5走の1角（または2角）通過順が 1〜2番手だった回数が2回以上の馬を「逃げ候補」とする。

| 逃げ候補の頭数 | ペース予想 |
|---|---|
| 0〜1頭 | スロー |
| 2頭 | ミドル |
| 3頭以上 | ハイ |

逃げ候補のうち前走で逃げて好走した馬がいれば、その馬のハナ主張を優先してペースを微調整してよい。

## 5. 各馬の評価（分析者が入力）

- `ability`（0〜100）: 近走の **着順ではなく内容** から見た能力。敗因（前詰まり・超スローで差し届かず・
  外回し・苦手条件の連続など、勧告対象外の不利も含む）を補正し、上位馬がその後上のクラスで好走していれば
  レースレベルを上げて評価する
- `style`: 逃げ / 先行 / 差し / 追込
- `gate_zone`: 内 / 中 / 外（今回の枠）
- 減点・加点フラグ（下表）

位置取り適性（`style` × ペース）とバイアス適性（`style`・`gate_zone` × バイアス）は機械的に計算する。

### 減点要素（あれば即切りではなく、重みとして合算）

| キー | 内容 | 重み |
|---|---|---|
| front_runner_bad_pace | 前走逃げて好走、今回は展開不向き | -6 |
| long_layoff | 半年以上の休み明け | -5 |
| wins_special_ground | 勝ちが重・不良など特殊条件に集中 | -4 |
| turf_to_outer | 芝で外枠替わり | -3 |
| dirt_to_inner | ダートで内枠替わり | -3 |
| fillies_to_open | 牝馬限定戦 → 牡牝混合戦 | -3 |
| slow_start | 出遅れ・煽り癖 | -4 |
| hates_kickback | ダートのキックバックを極端に嫌う | -4 |
| stable_concern | 厩舎コメントに不安要素 | -4 |
| weight_change_15 | 馬体重 ±15kg 以上 | -4 |
| weight_increase | 斤量増（別定・ハンデでの増量） | -2 |
| lucky_last_race | 前走が極端な展開の恩恵（前残り・差し決着）で好走 | -4 |
| lucky_trip | 前走が絶好の内枠・最短距離でロスなく回った | -2 |
| first_long_trip | 初の長距離輸送 | -2 |

### 加点要素（穴馬の激走条件）

| キー | 内容 | 重み |

| first_after_gelding | 去勢明け初戦 | +3 |

| big_distance_change | 400m以上の距離延長・短縮 | +2 |
| first_blinker | 初ブリンカー・初チークピーシーズ | +3 |
| breaking_out | 本格化の兆し（3〜5歳で苦戦続きから直近急に好走） | +4 |
| hill_23 | 坂路ラスト2F 23秒台 | +3 |
| hill_23_extra | 上記が終い重点、または併せ馬で先着 | +1 |
| short_interval_unfulfilled | 連闘〜中2週で、前走が力を出し切れていない | +3 |
| final_work_strong | 最終追い切り終い重点（CWラスト1F 11秒台後半など） | +3 |
| course_repeater | 同コース・同重賞で好走歴（リピーター） | +3 |
| second_start | 叩き2戦目 | +2 |

| good_in_higher_class | 前走は格上挑戦で着順以上に内容が良い | +3 |
| turf_to_inner | 芝で内枠替わり | +2 |

加点も即ヒモ入りではなく、バイアス・枠順・コース適性・他馬のレベルと合算した総合点で扱う。

## 6. 確率と期待値

1. 総合点 = ability + 位置取り適性 + バイアス適性 + 減点/加点の合計
2. 総合点をソフトマックス（温度 8）で **モデル勝率** に変換
3. 市場の単勝オッズから控除率を除いた **市場勝率** と、対数空間で 50:50 にブレンド
   （モデルの過信を防ぐ。比率は記録を見て補正する）
4. 複勝・ワイド・馬連・三連複の的中確率は Harville 式で算出
5. 期待値 = 的中確率 × オッズ。ワイド・複勝はオッズ下限を使う
6. 期待値 1.2 以上の馬券だけを買う

## 7. 券種と金額

- 対象券種: 単勝・複勝・ワイド・馬連・三連複（三連単は使わない）
- 期待値1.2以上の馬券のうち、ケリー比率 f = (p×o−1)/(o−1) の大きい順に最大15点
- 投資額 = 4,000円 × min(1, Σf × 4)。優位性が小さいレースほど投資額が小さくなる
- 投資額を f の比で配分し、100円単位に切り捨て（0円の馬券は捨て、余りは f の大きい順に100円ずつ戻す）

## 8. 記録と検証

毎レース `keiba/records/YYYYMMDD_レース名.json` に入力・買い目・結果を保存する。
重賞だけではサンプルが少ないので、30レースごとに要素の重み・ブレンド比率・購入閾値を見直す。
