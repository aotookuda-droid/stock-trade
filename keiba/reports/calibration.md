# 市場確率の補正と Harville 2・3着補正 — 検証結果と判断材料（2026-10-06）

対象は JRA 平地重賞 640 レース（2021-10〜2026-09、`keiba/data/graded_2021_2026.json`）。2021〜2024年の 416 レースで推定し、2025年〜の 224 レースで評価した。
再実行は `python3 -m keiba.research.calibration keiba/data/graded_2021_2026.json keiba/reports/calibration_results.md`。全表は [calibration_results.md](calibration_results.md)、推定値は [calibration_results.json](calibration_results.json) にある。
エンジン（engine.py・raceday.py・RULES.md）は変えていない。採用するかどうかはユーザーが判断し、Codex のレビューを経てから決める。

## 手法

- **市場の勝率 q**: 確定単勝オッズの逆数を発売対象馬で正規化したもの。競走中止（31頭）・失格は発売対象なので分母に残して着外とし、取消（19頭）・除外（18頭）は返還なので外す。`market_check.py` は中止を分母から外していたので、同じ扱いに直して再生成した（数値の変化は小さい）。
- **単勝の補正**: p ∝ q^β × κ^[単勝100倍以上]。β は対数オッズに単調な補正で、κ は100倍以上だけに掛ける追加の割引。β・κ を両方動かす版と、β=1 に固定して κ だけ動かす版を試した。
- **2・3着の補正（Benter 型）**: P(2着=b | 1着=a) = p_b^λ2 / Σ_{j≠a} p_j^λ2。3着も λ3 で同じ形。λ=1 なら Harville 式になる。
- **指標**: 勝ち馬・2着・3着のそれぞれについて条件付きの対数損失をとる。3つの和が三連単の着順の対数損失になる。同着の着順は評価しない。差の 95% 区間はレース単位のブートストラップで出した。ほかに、評価年に的中した馬連・ワイド・三連複の組について、単勝から作った確率と、その券種の払戻から逆算した市場確率（払戻率÷配当倍率）の平均対数確率を比べた。

| λ2（補正なしの勝率に対して） | 0.807 | 0.812 |

## 評価年（2025〜）の対数損失

三連単の着順の対数損失は、1〜3着がすべて一意の **221 レース**で、レースごとに3つの条件付き損失を足してから平均した。
初版（27d4161）では、対象数が違う着順別の平均（1着223・2着221・3着221レース）を足していたので、Codex の指摘を受けて直した。改善の向きは変わらない。

| 方式 | 三連単の着順 | 補正なしとの差 | 95% 区間 | 2025年（128） | 2026年（93） |
|---|---:|---:|---|---:|---:|
| 補正なし（単勝 Harville） | 6.7125 | — | | | |
| β のみ | 6.7437 | +0.031 | [+0.019, +0.045] | +0.033 | +0.029 |
| λ のみ | 6.6449 | **−0.068** | [−0.117, −0.018] | −0.083 | −0.046 |
| κ（β=1）＋ λ | 6.6412 | **−0.071** | [−0.123, −0.019] | −0.090 | −0.046 |

着順ごとの対数損失（評価できるレースの数は、勝ち馬 223・2着 221・3着 221）:

- **λ（2・3着の補正）**: 3着の差は −0.052（95% 区間 [−0.093, −0.010]）、2着は −0.015（[−0.042, +0.009]）。学習年でも −0.047・−0.017 と同じ向きで、2025年・2026年のどちらでも改善した。今回の結果のうち最も頑健だった。
- **β（単勝のべき乗）**: 勝ち馬の差は +0.002（[−0.004, +0.009]）で効果がなく、2・3着はむしろ悪くなった。採用しない。
- **κ（100倍以上の割引）**: 勝ち馬の差は −0.0050（[−0.0054, −0.0045]）。区間が狭いのは、評価年に100倍以上の 564 頭が1頭も勝たなかったため。再抽出しても大穴が勝ったときの損失が一度も入らず、学習で決めた κ の推定誤差も含まないので、将来も改善する証拠にはならない。市場の見積もりどおりでも、評価年に100倍以上が0勝となる確率は **7.1%** ある（レースごとに100倍以上の勝率の合計で勝つとし、レース間は独立と置いた。Codex の計算と一致）。

| 方式 | 学習年（1085頭） 予測／実際 | 評価年（564頭） 予測／実際 |
|---|---:|---:|
| 補正なし | 19.6 ／ 26 | 9.8 ／ 14 |
| λ のみ | 34.3 ／ 26 | 17.3 ／ 14 |
| κ ＋ λ | 25.2 ／ 26 | 12.7 ／ 14 |

補正なしの Harville は、100倍以上の馬の3着以内を約 3/4 に**過小評価**していた。勝率は過大評価ぎみでも、2・3着には市場の想定より多く来ている。λ だけを入れると今度は過大評価になり、κ と λ を組み合わせると両方の年で実際の数に近くなった。

評価年の対数損失は、ほぼ同じだった。λ のみで3着の差は −0.052 [−0.094, −0.009]、2着の差は −0.015 [−0.045, +0.014]。β のみでは2・3着が悪化した。

**100倍以上の馬（10年分を合わせて 3477 頭）**

| 方式 | 予測勝利数 | 実際 | 予測3着以内数 | 実際 |
|---|---:|---:|---:|---:|

## λ をモデル側とエンジン型の混合分布に当てはめた場合（追加検証）

`python3 -m keiba.research.calibration_model keiba/data/graded_2021_2026.json keiba/reports/calibration_model.md`（全表は [calibration_model.md](calibration_model.md)）

- **モデル側**: ability_calibration の客観能力を温度8のソフトマックスにした勝率を使った。本番の ability は分析者の主観なので、ここでは機械的な**代用品**になる。
- **市場側**: 単勝の Harville（エンジンの単勝代用の経路）。
- **混ぜ方**: engine.order_distribution と同じく、着順ごとに モデル^w × 市場^(1−w) で混ぜた。混ぜ方が一致することはテストで確かめた。
- **対象**: 客観能力が全馬で作れた 610 レース（学習 395、評価 215）。三連単・三連複・勝ち馬の評価は、1〜3着が一意の 212 レースでそろえた。

**モデル側の λ（学習年）**は λ2 = 0.797、λ3 = 0.685 で、市場側（0.807・0.692）とほぼ同じだった。評価年で推定し直すと 0.654・0.520 になる。

評価年の「λ なし」との差は次のとおり（95% 区間はレース単位のブートストラップ）。

| 方式 | 重み | 三連単の差 | 三連複の差 |
|---|---|---:|---:|
| モデル側だけ λ | w = 0.25（現行） | −0.027 [−0.038, −0.016] | −0.022 [−0.030, −0.013] |
| 市場側だけ λ | w = 0.25（現行） | −0.028 [−0.066, +0.009] | −0.007 [−0.038, +0.024] |
| 両側 λ | w = 0.25（現行） | −0.042 [−0.089, +0.004] | −0.019 [−0.058, +0.019] |
| モデル側だけ λ | w = 0.5（参考） | −0.055 [−0.078, −0.032] | −0.046 [−0.064, −0.028] |
| 市場側だけ λ | w = 0（参考） | −0.074 [−0.125, −0.025] | −0.053 [−0.096, −0.012] |

- モデル側だけに λ を入れると、どの重みでも三連単・三連複とも区間が 0 をまたがなかった。両側に入れた場合、三連単の差の平均は大きくなるが、三連単・三連複とも区間が 0 をまたぐ。w=0.5 で市場側だけに λ を入れると、三連複はかえって悪化した（+0.022 [+0.002, +0.042]）。
- これは**代用モデル（客観能力）と代用市場（単勝）の組み合わせ**の結果で、主観の ability・展開点・バイアスを含む本番のモデルと、三連単オッズの市場分布という主経路で同じだけ改善するとは限らない。三連単オッズの市場分布にはこの λ は関係しない。
- 重みの違いによる差も表には出ているが、重みの見直しはこの検証の目的外なので提案しない。

## 100倍除外を置き換えられるか

**まだ早い。** 当面は暫定ルール（判断時の単勝100倍以上を含む買い目は買わない）を続けるのがよい。理由は次のとおり。

1. 100倍以上の馬の勝率が市場より低いことは、10年分の参考集計でようやく境目の有意になった程度（8 勝、比 0.50、区間 0.22〜0.99。学習期間を含み、外部検証ではない）。κ の推定値は学習期間では 0.58〜0.60 で安定しているが、評価年だけで推定すると 0.05 になる（勝ちが 0 件のため）。
2. 3着以内について見ると、100倍以上の馬は補正なしの Harville より**多く**来ている。一律に除外すると、ワイド・三連複では過小評価されていた側を捨てている可能性がある。一方で λ を入れると、今度は100倍以上の2・3着を持ち上げすぎる（10年分で予測 113 に対して実際 75。κ を足しても 85）。**λ を採用するなら、100倍除外を外すとこの過大評価が買い目にそのまま出る。λ の採用と100倍除外の解除は、別々に判断し、同時にはしない方が安全。** これらがエンジンの買い目の損益にどう効くかまでは、今回の材料では分からない。
3. エンジンの市場側の分布は、三連単オッズがそろっていれば三連単オッズから作り、単勝の Harville は代替にしか使わない。今回検証したのは「単勝から作る分布」の補正で、三連単市場そのものに人気薄の偏りがあるかは見ていない（過去データには的中組の払戻しかなく、全組のオッズがない）。モデル側について確かめたのは λ だけで、それも客観能力という代用品での確認。κ（100倍以上の割引）は市場の単勝オッズの性質で、モデルの点数が付けた勝率に当てはめる根拠はない。
4. 過去データは確定オッズで、運用は発走10分前のオッズを使う。この差は今回は検証できない。判断時点のオッズは records の odds／odds_meta に 10/4 の 2 レース分（全券種）しかない。

**採用候補として有力なのは λ（2着 ≈0.78〜0.81、3着 ≈0.69）。** 学習期間を変えても値が安定し、評価年で3着の改善が有意で、券種の市場との差も縮めた。モデル側（客観能力）でも同じ値（0.80・0.69）が推定され、エンジン型の混合分布（代用経路）でも改善した。ただし本番の主経路での効果は未確認。

Codex の確認（2026-10-06）を受けて、**本番採用は保留し、参考試算として並行に保存する**ことにした（次節）。数レースの仮想収支を根拠に、重みや混合率の変更は提案しない。

## 参考試算への追加と、方式の固定（2026-10-06）

- **方式と係数を固定した。** 以後この検証のあいだは変えない。
  - モデル側: λ2 = 0.797、λ3 = 0.685（`engine.PLACE_DISCOUNT_MODEL`）
  - 単勝代用の市場側: λ2 = 0.807、λ3 = 0.692（`engine.PLACE_DISCOUNT_WIN_MARKET`）
  - 推定はどちらも 2021〜2024年。三連単オッズの市場分布には掛けない。κ は入れない。
- **混合率 0.25・温度 8・100倍除外は本番と同じに固定した。** 判断時に `reference.lambda_model`（モデル側だけ）と `reference.lambda_both`（単勝代用のときは市場側にも）を保存する。保存するのは買い目・勝率（混合後の分布から集計し直したもの）・3着以内の確率で、台帳には入れない。精算では「参考（λ・モデル側）」「参考（λ・両側）」として本番と並べる。本番の買い目と勝率は変わらないことを、10/4 の2レースで確かめた。
- **独立した Codex の1着勝率には λ を入れない。** λ は2・3着の補正で、単独モデルの1着の確率は変えない（`benter_orders` の1着への集約は勝率のまま。テストで確認）。
- **評価の扱い**: 2025年〜のデータは、方式の比較と選択に何度も使ったので、もう未使用の検証データではない。採用の判断は、上の方式を固定したまま、今後の未使用のレース（2026-10-11 以降の判断時点の記録）で見る。
  - 予測の評価: 三連単の着順・三連複の対数損失と、3着以内の確率帯ごとの実績。
  - 馬券の評価: 仮想収支とリスク。予測精度が改善しても、回収率の改善は保証されない。
- **再現のための記録**: 入力データ・能力パラメータ（ability_calibration.json）・推定値の SHA-256 と、期間・件数・分割・ブートストラップの設定を、`calibration_results*.json` と `calibration_model.json` の `meta` に残した。


## 次に必要なこと

- **判断時点オッズの蓄積**: records に全券種のオッズ（三連単を含む）がたまれば、(a) 発走10分前と確定オッズの差、(b) 三連単市場に人気薄の偏りがあるか、を同じ方法で検証できる。
- **100倍以上の標本を増やす**: 2016年以降を足しても勝ちは 8 件。重賞以外（オープン・3勝クラス）を足せば増えるが、市場の性質が重賞と同じとは限らない。
- **判断時点の主観 ability の記録の蓄積**: 本番の主経路（主観の ability ＋ 三連単市場）での λ の効果は、記録がたまってから、固定した方式のまま評価する。
- **分布の端に強い2・3着の補正**: λ が100倍以上を持ち上げすぎる点に対して、オッズ帯で λ を変える、あるいは Lo–Bacon-Shone などの別の形を、同じ年分割で比べる。
- 上の結果がそろったら、「除外の継続」「κ のみ」「κ ＋ λ」「1着を要求する買い目だけ制限」を、判断時点のオッズで比べる。予測は対数損失・Brier・確率帯ごとの実績で、馬券は仮想収支とリスクで、分けて評価する。100倍除外は候補の馬券を制限するもので、その馬の確率を0にするものではない。勝率の過大評価だけでは、100倍以上を含む全券種の買い目が不利だとは言えない。

## 限界

- 確定オッズでの結果であり、発走10分前のオッズでは検証していない（上記 4）。
- 評価年は 224 レースで、100倍以上の勝ちは 0 件だった。人気薄に関する推定は、10年分を合わせても不確かさが大きい。
- モデル側の検証（calibration_model）は 2021年以降のデータだけで行った。2016〜2021年の馬の戦績はキャッシュになく、取得していない。
- 券種の市場確率は払戻率を一律と置いて逆算した近似で、端数の切り捨てや特払いは考慮していない。
